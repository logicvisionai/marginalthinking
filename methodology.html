Como a pesquisa é produzida

O objetivo é reduzir ruído, separar evidência de interpretação e manter cada publicação auditável do dado bruto à conclusão.

EvidênciaAnáliseFormato canônicoPipelineValidaçãoRevisões

Hierarquia de evidência

Dados oficiais, bancos centrais, organismos multilaterais, documentos regulatórios e séries primárias têm prioridade. Imprensa financeira e pesquisa secundária entram para contexto, confirmação e acontecimentos recentes. Uma afirmação importante deve permitir rastrear de onde veio o número, qual é a data de referência e se houve revisão metodológica.

Fato, inferência e cenário não são a mesma coisa

O texto separa o que foi observado do que é interpretação. Cenários são condicionais: devem indicar gatilhos, mecanismos e contraprovas. A análise evita transformar correlação diária em causalidade e evita somar estoques, fluxos e valorizações como se fossem a mesma variável.

HTML + Markdown

O Markdown é a fonte canônica da pesquisa. O HTML é uma camada de leitura gerada a partir desse conteúdo. Não há PDF, DOCX ou XLSX paralelo para manter. Isso elimina divergência entre versões e reduz o custo de publicação.

Elementos suportados

  • títulos e subtítulos;
  • listas numeradas e não numeradas;
  • tabelas Markdown responsivas;
  • citações e links;
  • blocos de código;
  • diagramas causais com setas;
  • gráficos declarativos quando uma série numérica realmente melhora a leitura.

Pipeline editorial

01Pesquisar

Coletar fontes, datas, números, revisões e contexto.

02Estruturar

Definir a pergunta, o mecanismo causal, as alternativas e os indicadores.

03Escrever

Produzir o relatório completo em Markdown, sem gerar anexos binários.

04Validar

Checar estrutura, tabelas, links, caracteres quebrados e referências proibidas.

05Publicar

Adicionar o shell HTML e o índice do arquivo. A home é atualizada automaticamente.

06Revisar

Correções posteriores substituem a versão publicada com registro no Git.

Validação automática

O build falha se houver relatório sem Markdown correspondente, arquivo binário no diretório de pesquisas, referência a PDF/DOCX/XLSX, caractere de substituição Unicode, bloco de código sem fechamento ou tabela Markdown estruturalmente inconsistente. A automação deve parar antes do deploy, não depois.

Revisões e incerteza

Números preliminares podem mudar. Quando uma série é revisada, o texto deve indicar o que mudou e por quê. Nível de confiança é uma propriedade da evidência e do mecanismo, não uma forma de dar aparência de precisão.
