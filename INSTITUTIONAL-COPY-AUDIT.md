# Marginal Thinking — institutional copy audit

The public institutional pages should state concrete subjects, procedures and limits. They should not use slogans or abstract language to imply rigor.

## Audit findings corrected in the current copy

- Replaced the home statement `Analysis should show its reasoning boundary` / `Uma análise deve mostrar os limites do próprio raciocínio` with a concrete description of how evidence, interpretation, uncertainty and revision are handled.
- Removed `control of bottlenecks` / `controle de gargalos` from the research-program description and replaced it with named categories of assets and productive capacity.
- Removed `cross-asset transmission` from the Portuguese home copy and explained which markets interact.
- Removed broad claims such as `forces that redistribute wealth and power` where a specific research scope can be stated instead.
- Rewrote Method around observable procedures: question definition, source selection, source tracing, evidence versus interpretation, causal mechanisms, stocks versus flows, scenarios, confidence and revision.
- Rewrote About around concrete questions: subject, name, coverage, interdisciplinary links, meaning of an assessment, audience and purpose of the archive.
- Removed expressions such as `disciplined uncertainty reduction`, `signal from noise`, `structure and conjuncture`, `headline speed` and `flattening complexity` from the institutional copy.

The canonical institutional text is stored in `data/institutional-copy.json` and is merged into the locale file before rendering. `INSTITUTIONAL-EDITORIAL.md` defines the standard for future changes.
